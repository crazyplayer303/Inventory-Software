# Inventory Software

This repository contains a basic skeleton for an inventory management system.

## Structure

```
backend/        # Flask backend application
frontend/       # Frontend assets (placeholder)
db/             # SQL schema and seed data
```

### Backend
- **app/** – Python modules for the Flask application
- **config.py** – Configuration values
- **requirements.txt** – Python dependencies

### Frontend
- **public/** – Static HTML, including `test.html` which displays a simple page to confirm the setup
- **src/** – Frontend source code (JavaScript)
- **package.json** – Frontend dependencies

### Database
- **schema.sql** – Database schema
- **seed.sql** – Example seed data

This is only a starting point. Expand each section as development continues.
